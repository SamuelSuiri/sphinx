## What failed
- **`test (macos-latest, 22)`, run 39006743791:** `check-cancellation.test.js` › "cancellation while the final grade is in flight…" › SIGINT failed with ENOENT on `fixture-state/grade-terminated`. `macos-latest, 24` was cancelled by fail-fast.
- **Cause:** the fake provider wrote `<phase>-ready` *before* installing its SIGTERM handler. The test cancels as soon as it sees `ready`. If the runner's SIGTERM landed in that window, it took the default fatal action, so `-terminated` was never written.
- **Reproduced locally:** with a 100ms gap after `ready`, the old order fails 4/4 and the new order passes 4/4. A gap of 250ms or more is invalid for this check, because `runProcess` escalates to SIGKILL at 250ms.
- **Fix (test only):** install the SIGTERM handler before announcing readiness.

## Release-review finding, also fixed
- `git-continuation.test.js` › yolo: "Unexpected end of JSON input" (an earlier ubuntu-24 run). The fixture wrote polled files (`ready-N.json`, `.approval`, `.decision`) with plain `writeFile`, which truncates the file and then writes it, so a poll could read an empty file.
- **Fix:** both the launcher and `release()` now publish these files with a temp-file write followed by `rename`. No test assertions changed, and no production code changed.
