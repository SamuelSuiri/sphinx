## CI repair (root causes reproduced locally with Node 22.23)
1. **`reviewer-recovery` "review deadline reports a readable timeout"** (CI ubuntu/22, every run): `AbortSignal.timeout()` uses an **unref'd** timer. When a model call waits only on the abort, nothing keeps the event loop alive, so Node 22 cancels the test ("Promise resolution is still pending"). This reproduced every time when running the whole file (26 pass, 1 cancelled). **Fix (src):** `runReviewer` now owns a referenced `setTimeout` and AbortController, aborts with a `TimeoutError` DOMException (so the existing REVIEWER_TIMEOUT mapping is unchanged), clears it in `finally`, and passes `timeoutMs` and `timeoutSignal` into `review()`. Result: 27/27 on Node 22.
2. **`git-continuation` "commit -a and --only…"**, two separate races:
   - `ENOTEMPTY rmdir .git/objects/pack` during cleanup (CI uses Git 2.55, which runs post-commit and receive maintenance **detached**). Fix: the fixture's temporary global gitconfig sets `maintenance.auto=false` and `gc.auto=0`. This can't be reproduced locally (Git 2.39 runs maintenance synchronously), so CI will be the check.
   - `Unexpected end of JSON input`: the test polled `ready-N.json` while the hook launcher was still writing it, and the launcher polled `.decision`/`.approval` the same way. This reproduced locally under full-suite load. Fix: both sides now publish via write-temp-then-rename.
3. **`reviewer.test.js` "first native or structured request…"** (local full-suite failure, also on clean main): it's the first `runReviewer` call in the file, and the cold `pi-runtime.js` import (~700 ms when idle, >2 s under load) counted against the 2 s review deadline. Under 8× parallel load it failed 8/8 on both main and the branch. Fix: a `before` hook pre-imports the Pi runtime; afterwards it passed 8/8 under the same load. Also widened the in-flight deadline test from 20 ms to 200 ms. It once failed locally because the deadline fired before the provider was reached (`providerSignal` undefined); the provider still never resolves, so the deadline still fires in flight.
